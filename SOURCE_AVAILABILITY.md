# Source availability — no open-source licence

Le Studio's source is published so it can be read, studied and reviewed.

**This publication does not grant an open-source licence.** No permission is
granted to redistribute, sublicense, sell, or incorporate this code or its
content into another product. The repository carries no open-source licence
file precisely because no open-source grant is intended at this time.

If you want to use Le Studio beyond reading and running it locally for your
own study, contact the repository owner.

## Why this file exists

A repository without a licence defaults to "all rights reserved", but that is
easy to miss when the source is publicly readable. This file makes the
decision explicit: source availability is not an open-source licence.

## Content and privacy commitments that stay in force regardless

- Learner data stays local-first and private by architecture; nothing here
  grants a right to collect it otherwise.
- Authenticated audio content must carry source + licence/consent metadata
  (see `src/lib/authenticAudio.js`); publishing source does not transfer any
  third party's rights in recordings.
